Simulador de código abierto escrito en HTML, CSS y JavaScript, con un núcleo de cálculo en C++ compilado a WebAssembly y scripts de Python para cada transformación. Versión 1.0, noviembre de 2026. Validación interna: pendiente.

Informe del proyecto, manual de usuario y escrito sobre la importancia de las transformaciones lineales. Autores: Andrés Mauricio Peñaloza Fernández y Eliana Carolina María Wong Lubo. Profesor principal: PhD Ellery G. Chacuto López (Álgebra Lineal Aplicada). Profesores: Luis Mario Duarte (Álgebra y Geometría Analítica); Ing. Jaris González e Ing. David De León (Introducción a las Ciencias del Agua y a la Tecnología).
